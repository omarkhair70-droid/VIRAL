# User Personas — Season 2

## 1) المستخدم العملي
- **Need:** Fast, simple path to exchange unused items for useful value.
- **Fear:** Wasting time in unclear flow or low-quality offers.
- **What Baddelha must show:** Clear publish flow, clear offer outcomes, organized next steps.
- **Future features that help:** Publish Item 2.0, Offer Flow 2.0, Deal Room 2.0.

## 2) صاحب الحاجة اللي ليها قصة
- **Need:** Space to explain meaning/context of item.
- **Fear:** Item gets treated as generic cheap second-hand listing.
- **What Baddelha must show:** Story-first item detail and respectful presentation.
- **Future features that help:** Story fields, Item Detail 2.0 story section, Story Item labels.

## 3) Creator / Artist
- **Need:** Premium presentation for meaningful pieces when trust layer is ready.
- **Fear:** Fake claims, chaos, or low-trust exposure.
- **What Baddelha must show:** Curation, credibility signals, and calm brand environment.
- **Future features that help:** Creator Drops strategy, manual curation, Profile 2.0 + trust badges.

## 4) المستخدم الحذر
- **Need:** Reliable trust signals before committing to a swap.
- **Fear:** Misleading items, unsafe interactions, unclear identity.
- **What Baddelha must show:** Reviews, completed swaps, profile clarity, safety reminders, report path.
- **Future features that help:** Trust Badges 2.0, stronger profile hierarchy, deal room reminders.

## 5) المستكشف
- **Need:** Interesting inventory and stories worth browsing repeatedly.
- **Fear:** Repetitive low-context listings and no reason to return.
- **What Baddelha must show:** Fresh story-backed items, featured selections, evolving drop culture.
- **Future features that help:** Story Items + Drops, featured modules, App Feel 2.0 discovery polish.
