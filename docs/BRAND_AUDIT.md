# BRAND AUDIT — Phase 19

## A) Brand Name
- **Arabic name:** بدّلها
- **English reference (optional):** Baddelha / Baddelha Swap
- **Positioning note:** Arabic-first brand, local voice first, English is secondary support only.

## B) Core Line
- **"بدّل الحاجة بدل ما تسيبها مركونة."**

## C) Brand Promise (Egyptian Arabic)
بدّلها بتدي الناس فرصة يحوّلوا الحاجات المركونة لقيمة حقيقية، عن طريق مقايضات مفيدة وواضحة بين ناس حقيقية.

## D) Brand Personality
- **Practical:** المنتج لازم يحسّسك إنه بيساعدك تاخد خطوة عملية، مش مجرد كلام تسويقي.
- **Warm:** الأسلوب إنساني وقريب، من غير تكلف.
- **Trustworthy:** الوعود واقعية، ومفيش مبالغة في الأمان أو النتائج.
- **Local:** اللغة والمواقف قريبة من المستخدم المصري.
- **Light but not childish:** خفيف ومريح، لكن ناضج.
- **Smart but not corporate:** مرتب وواضح، بدون لغة شركات تقيلة.

## E) Tone of Voice
### Do
- مصري واضح.
- جمل مباشرة وسهلة.
- نبرة هادية.
- توجيه أمان عملي.

### Avoid
- fake hype.
- "آمن 100%" أو أي ضمانات مطلقة.
- slang طفولي.
- مصطلحات corporate تقيلة.
- وعود مبالغ فيها.

## F) Current Brand Gaps
1. الهوية البصرية لسه مش متطبقة كنظام كامل.
2. الشعار/الأيقونة لسه functional على مستوى PWA أكتر من Brand system.
3. نظام الألوان مش موثق كـ tokens واضحة.
4. hierarchy للخطوط محتاج قواعد رسمية.
5. Empty states والمايكروكوبي نبرتها مش موحدة بالكامل.
6. Social sharing لسه ضعيف في التعبير البراندي.

## G) Brand System Needed Next (Phase 20)
- Logo rules
- Color tokens
- Typography system
- Spacing rhythm
- Tone guide
- Buttons/cards personality direction
- App icon refinement
- Social preview style
- Launch caption bank
- Trust/safety copy system

## H) Suggested Slogan Set
- **Primary:** بدّل الحاجة بدل ما تسيبها مركونة.
- **Secondary:**
  - اللي مركون عندك ممكن يكون مطلوب عند غيرك.
  - مش لازم تبيعها رخيص… بدّلها بحاجة تنفعك.
  - حاجتك ليها فرصة تانية.

## I) Brand Risks
- لو الهوية البصرية فضلت generic، المنتج هيتشاف كأنه template.
- لو النبرة بقت playful زيادة، الثقة هتقل.
- لو safety copy ضعيفة أو مبهمة، سلوك المقايضة هيبقى مقلق للمستخدم.
