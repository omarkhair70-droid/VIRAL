# Closed Beta Launch Plan (Phase 25)

## A) Launch status
- Controlled closed beta.
- Not a public launch.
- Invite-only by manual sharing.

## B) Goal of this beta
- Test whether users understand the swap loop.
- Validate image upload stability.
- Validate offer/deal/message/review/report/feedback flows.
- Find confusing screens before scaling.

## C) Beta waves
### Wave 0 — Internal check
- 2–3 accounts.
- Run one complete swap.
- Confirm feedback/admin pages.

### Wave 1 — 10 trusted users
- Friends/close testers.
- Each user should publish at least 1 item if possible.
- Collect confusion/bugs.

### Wave 2 — 25 users
- Only if no P0 bugs.
- Observe real offer behavior.
- Look for upload/message/report issues.

### Wave 3 — 50 users
- Only if image uploads and offer/deal flows remain stable.
- Prepare for public waitlist later.

## D) Entry links
- `/beta`
- `/items`
- `/items/new`
- `/feedback`
- `/install`

## E) What to ask testers to do
- Create profile.
- Publish one item.
- Browse marketplace.
- Send one offer.
- Try redirected follow-up if possible.
- Complete a test deal if possible.
- Leave review.
- Send feedback if confused.

## F) What to track manually
- Signups.
- Profiles completed.
- Items published.
- Offers sent.
- Offers accepted.
- Deals created.
- Deals completed.
- Reviews.
- Reports.
- Feedback.
- Upload issues.
- Confusing screens.

## G) Stop/hold conditions
Stop expansion if:
- Login is broken.
- Image upload regularly fails.
- Users cannot create offers.
- Accept/deal flow breaks.
- Messages fail.
- Privacy leak is suspected.
- Admin cannot review reports/feedback.
- 5xx errors appear repeatedly.

## H) Expand conditions
Move from 10 to 25 only if:
- No P0 bugs.
- At least several successful item publishes.
- Offer flow tested by real users.
- Feedback reviewed.
- Admin ops checked.
- Smoke test passes.
