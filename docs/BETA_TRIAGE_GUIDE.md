# Beta Triage Guide (Phase 25)

## Severity definitions

### P0
- Auth broken.
- Publish broken.
- Offer/deal creation broken.
- Privacy/security issue.
- Repeated 500 errors.
- Admin cannot review safety reports.

### P1
- Image upload flaky.
- Confusing flow blocks user.
- Notifications are misleading.
- Feedback/report issue.
- Mobile nav covers action.

### P2
- Copy issue.
- Minor layout issue.
- Polish.
- Slow but usable.

## Triage flow
1. Check feedback/admin reports.
2. Reproduce.
3. Categorize.
4. Fix or document.
5. Retest.
6. Decide whether to continue beta wave.
