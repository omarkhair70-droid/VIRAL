# Creator Drops Strategy — Season 2

## A) What Creator Drops Are
A premium layer where artists/creators can list meaningful items:
- jacket from a concert
- camera from a project
- sketchbook
- event piece
- studio item
- backstage item

## B) Why Not Now as a Full System
- Need stronger profile, item story, and item detail first.
- Need manual moderation/curation.
- Need trust and safety before public creator layer.

## C) MVP Version Later
- Admin marks item as featured/drop.
- Drop label appears.
- `/drops` page later.
- Featured on home.
- Manual only first.

## D) Drop Types
- Artist Drop
- Creator Closet
- Event Piece
- Story Item
- Limited Swap

## E) Risks
- Fake celebrity claims.
- Overhype.
- Unsafe public attention.
- Need verification later.

## F) Rules
- No fake claims.
- No celebrity implication unless verified.
- Keep drops curated.
- Start manually.
- No payments/auctioning in first version.


## Phase 33 status update
Manual MVP drops layer is now implemented (featured story items + curated drops + public /drops + admin curation).
Creator verification ecosystem and broader creator program remain in later phases.
