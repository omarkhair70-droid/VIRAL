# Baddelha UI Icon Usage Map v1

## Navigation
- `/` or home shortcut → `home`
- `/items` → `market`
- `/items/new` → `publish`
- `/notifications` → `bell`
- `/dashboard` → `profile`

## Marketplace
- Search → `search`
- Filters → `filter`
- Category tag → `tag`
- Empty marketplace → `empty-box`

## Story Swap
- Story item marker → `story`
- Swap interaction → `swap`
- Offer states → `offer`
- Deal room → `deal`

## Safety and Operations
- Safety center → `shield`
- Report abuse → `report`
- Feedback center → `feedback`
- Warning alert → `warning`

## Common actions
- Share → `share`
- Copy → `copy`
- Edit → `edit`
- Delete → `trash`
- Upload → `upload`
- Camera / images → `camera`, `image`
- Back / Forward → `back`, `forward`
- Logout / Settings → `logout`, `settings`
