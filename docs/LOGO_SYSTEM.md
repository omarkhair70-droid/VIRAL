# Baddelha Logo System — Final v1

## Direction
Final direction: **Concept C refined**.

The mark is not a literal Arabic letter. It is an abstract exchange loop inspired by the idea of **two sides / two items / two people** meeting through a calm swap.

## Meaning
- **Loop motion:** exchange, continuation, second chance.
- **Two lower dots:** two people or two items in the swap.
- **Open form:** the item gets a new path, not a closed ending.
- **Clay:** warmth, movement, local character.
- **Ink:** trust, stability, seriousness.
- **Sage:** calm balance and safety.

## Correct Arabic Name
Use: **بدّلها**

Do not use:
- بدلها
- يدّلها
- يدله

## Usage
- App icon / PWA icon: use `public/icons/icon.svg` or PNG sizes.
- Header: use `public/brand/baddelha-horizontal.svg` if browser text rendering is acceptable, or PNG fallback `baddelha-horizontal.png`.
- Social/profile image: use `public/icons/icon-512.png`.
- Docs/preview: use `public/brand/baddelha-logo-preview.png`.

## Note
The SVG wordmark uses browser font rendering with an Arabic font stack. The PNG wordmark is rendered correctly using Arabic shaping and should be used when exact Arabic appearance is required.
